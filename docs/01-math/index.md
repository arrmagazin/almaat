The formal core: the primitive `Azon` and the structures built directly from it.

- [Azon](00-azon.md) — Azon is the framework's sole primitive: an ability to respond to each given Tik with a specific Tok, constrained by three axioms.
- [Sets, Equivalence, Topology](01-sets.md) — Set and its Elements, the equivalence relations that compare Azons, and the topological structures over Collections of Sets.
- [Composition](02-composition.md) — The Arrow and the Composition that feeds one Azon's output into another — associativity, bijection, wel-consumption, Identity, Null.
- [Graph](03-graphs.md) — Graph as a Set of Arrows, the Vertex types classified by in/out connectivity, the Path and Tree built on them, and what makes a Graph connected.
- [Numerals](04-numerals.md) — Natural numbers (Number), rationals (Ratio, Rational), intervals, sequences, and selections.
- [Spaces](05-spaces.md) — The Space as a Tuple of Axis, and the Cluster, Point, Volume, and Form built on it.
- [Structures](06-structures.md) — The Structure: a Set equipped with Operations constrained by Laws, and the standard algebras built from them — magmas, ringoids, and lattices.
- [Formal Language](08-language.md) — How a Language is built from binary Code up through Alphabet, Word and Dictionary, the Rules and Grammar that transform them, the Theory derivable from an Axiom, and the four nested classes of Grammar.
- [Probability](09-probability.md) — The SampleSpace and its Events, the Probability Measure and Distribution over them, conditioning up to Bayes' Theorem, Random Variables with their moments, and the limit laws over a growing Sample.
