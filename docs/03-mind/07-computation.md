Computation *(Liqenne\*)*
: The process of [`Reasoning`](08-reasoning.md) by executing `Dataflow` on given input by some real `Runtime` until the outcome is evaluated.

## Data and Transformers

Data *(Danyja\*)*
: A `Text` that contains some `Information`.

---

Information *(Infa)*
: A `Message` encoded in `Data` that has precise influence on a receiver.

---

Transformation *(Perawtvarenne\*)*
: Replacing input data with output data in some deterministic way.

---

Transformer *(Perawtvaralnik\*)*
: A specific circuit that deterministically consumes input data, transforms it, and provides output data under some `Algorithm`.

---

Dataflow *(Rux Danyx\*)*
: Interdependent exchange of computed data between `Transformers` over time.

---

Runtime *(Vykananne\*)*
: A system of transformers able to execute dataflow — recognize, store, access, interpret, and transform `Data`.

---

Runtime-Contract *(Damova Vykanannia\*)*
: Conditions and limitations that guarantee predictable `Runtime` behavior; errors reported when violated.

## Program

Program *(Pragrama)*
: Text in some formal language interpreted by a `Runtime` as instructions for `Data` transformations.

---

Referential Transparency *(Spasylkavaja Prazrystasc\*)*
: Ensuring an expression can be replaced with its value without changing program behavior.

---

Equivalence (≡) *(Rawnaznaqnasc\*)*
: Ensuring two expressions can be safely swapped in program text.

---

Equational Reasoning *(Rawnannae Razvazhanne\*)*
: Ability to infer truths about a system from its parts; possible when composed of expressions devoid of side effects.

## Algorithm and Correctness

Algorithm *(Algarytm\*)*
: A prescription for how to apply certain transformations on data pursuing a specific goal; may halt with terminal output or never halt.

---

Specification *(Apisanne\*)*
: Formal properties used to outline expected output of an algorithm in correspondence to its input.

---

Correctness *(Slushnasc\*)*
: Satisfaction of an algorithm's actual computation with respect to a priori defined specification.
