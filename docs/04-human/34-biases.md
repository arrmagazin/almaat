## What is Cognitive Bias?

A [`Bias`](11-intellect.md) is a systematic error in thinking that occurs while processing and interpreting information, affecting the decisions and judgments that follow.

Biases occur due to limitations of the human brain:

- Simplifying information processing via creating shortcuts
- Problems with memory, attention, attribution
- Ego motivations
- Social pressures, tribalism
- Attaching deeper identity/emotional meaning

## Categories of Cognitive Biases

### Laziness of Mind

| Bias | Description |
| --- | --- |
| **Mere Exposure** | Tendency to develop a preference for things simply because they are familiar |
| **Confirmation Bias** | Tendency to seek out, interpret, and remember information that confirms existing beliefs while dismissing contradictory evidence |
| **Anchoring** | Relying too heavily on the first piece of information (the "anchor"); subsequent judgments adjust from that anchor |
| **Availability Heuristic** | Placing greater value on information that comes to mind quickly |
| **Commitment and Consistency** | Tendency to behave consistently with commitments once made |
| **Misinformation Effect** | Post-event information interfering with memory of the original event |
| **Attentional Bias** | Paying attention to some things while simultaneously ignoring others |
| **Functional Fixedness** | Seeing objects as only working in a particular way |
| **Illusory Truth Effect** | Believing information if it's repeated often, regardless of accuracy |
| **Cognitive Dissonance** | Feeling discomfort when holding conflicting beliefs, leading to changes in attitudes or behaviors |
| **Halo Effect** | Overall impression of a person influences how you think about their character; the first trait learned outshines the rest |
| **Gambler's Fallacy** | Believing past random outcomes change future ones, expecting a streak to "balance out" when each event is independent |
| **Frequency Illusion** | After first noticing something, you perceive it more often and mistake the heightened attention for a real rise in frequency (the Baader-Meinhof phenomenon) |
| **Serial Position Effect** | Items at the start (primacy) and the end (recency) of a list are remembered better than those in the middle[^1] |
| **Forer (Barnum) Effect** | Accepting a vague, flattering sketch as a precise description of yourself[^5] |
| **Hindsight Bias** | Once the outcome is known, believing you saw it coming[^6] |
| **Peak-End Rule** | Judging a past experience by its most intense moment and its end, not by its length[^7] |
| **Zeigarnik Effect** | Unfinished tasks stay in memory more than finished ones; writing down a plan to finish is enough to quiet the pull |

### Self-Regard

| Bias | Description |
| --- | --- |
| **Self-Serving Bias** | Blaming external forces for failures and taking credit for successes |
| **Actor-Observer Bias** | Attributing your own actions to external causes while attributing others' behaviors to internal causes |
| **Better-Than-Average Effect** | Rating yourself above the average person on most traits and abilities, most strongly on moral traits — across over 950,000 people[^3] |
| **Dunning-Kruger Effect** | Less skilled individuals overestimate their abilities |
| **False Consensus Effect** | Overestimating how much other people agree with you |
| **Optimism Bias** | Believing you are less likely to suffer misfortune and more likely to succeed than your peers |
| **Bias Blind Spot** | Seeing biases in others more readily than in yourself: of 661 adults, one rated himself more biased than the average person[^4] |
| **Spotlight Effect** | Overestimating how much others notice and judge your actions and appearance |

### Tribalism

| Bias | Description |
| --- | --- |
| **Conformity** | Yielding to group pressure to match others' judgments, even against the evidence of your own senses. See [Conformism](../06-socium/36-conformism.md) |
| **Social Proof** | Looking to others for cues on how to behave, especially in unfamiliar situations |
| **Bandwagon Effect** | Adopting beliefs or behaviors because many others do the same |
| **In-Group Favoritism** | Favoring members of one's own group over those in other groups |
| **Reciprocity** | Wanting to give back when we receive something |

### Evaluation

| Bias | Description |
| --- | --- |
| **Labor Illusion** | Valuing a result more when the effort behind it is made visible |
| **Loss Aversion** | Preferring to avoid losses over acquiring equivalent gains |
| **Sunk Cost Fallacy** | Continuing a behavior due to previously invested resources, even when irrational |
| **Scarcity Bias** | Valuing things more when they are rare or perceived to be limited |
| **Contrast Effect** | Judging something by what sits next to it rather than on its own merits — a cost feels small beside a larger one |
| **Paradox of Choice** | Too many options reduce satisfaction and stall decisions instead of helping; more alternatives mean more regret and comparison |
| **Time-Saving Bias** | Misjudging the time saved by going faster: overestimated when speeding up from an already high speed, underestimated from a low one[^2] |
| **Regression to the Mean** | Reading the drift of an extreme result back toward the average as a real effect of whatever came in between[^8] |
| **Survivorship Bias** | Judging from the winners you can see while the identical efforts that failed stay invisible. See [Luck & Serendipity](../05-mastery/10-luck.md) |

## Logical Fallacies

| Fallacy | Description |
| --- | --- |
| **Composition** | Assuming what is true of a part is also true of the whole |
| **Division** | Assuming what is true of a whole must be true of all its parts |
| **Circular Argument** | Using the same statement as both premise and conclusion |
| **Non-Sequitur** | An argumentative leap where the conclusion does not follow from the premises |
| **Irrelevant Conclusion** | Conclusion concerns something other than what the argument was trying to prove |

## Communication Fallacies

| Fallacy | Description |
| --- | --- |
| **Ambiguity** | A term has more than one meaning |
| **Equivocation** | A single word used in two different senses |
| **Amphiboly** | Ambiguity arising from sentence structure |
| **Emphasis** | Incorrect emphasis of words in a sentence |

## Contextual Fallacies

| Fallacy | Description |
| --- | --- |
| **Quoting Out of Context** | Manipulation of the context of a quotation |
| **Framing Effect** | How information is presented influences choices |
| **Argument from Ignorance** | A statement cannot be proved true just because there is no evidence to disprove it |
| **Ad Hominem** | Attacking the person rather than the argument |
| **Appeal to Authority** | Truth cannot be proven merely because an "authority" says it |
| **Appeal to Sentiments** | Using emotions to persuade rather than prove |
| **Statistics Manipulation** | Statistics can be biased to "prove" many different hypotheses |
| **Texas Sharpshooter** | Drawing the target around the bullet holes after firing — cherry-picking or clustering data after the fact to fit a hypothesis, then claiming it was predicted |
