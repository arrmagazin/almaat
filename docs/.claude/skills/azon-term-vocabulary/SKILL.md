# Azon term vocabulary

Use `Arg` for an Azon's input and `Spond` for its output, with plurals `Args` and `Sponds`. Never write `Tiks` or `Toks`, in prose, sets, composition, or formulas.

- When a term is renamed, replace every occurrence across the docs in the same pass, then grep for the old word to confirm zero hits.
- `Taxon` is complete only when it has one `Fragment` per `Spond`, with both directions stated in its formula.
- Rewrite candidate formulas in the new vocabulary; do not leave old names in a draft for later.
