# ALMAAT

A general-purpose layered knowledge base for cognitive modeling.

It is for anyone who wants a single consistent vocabulary for thinking about minds, systems and how to live.

Read it at <https://almaat.web.app>. The site and the EPUB / PDF builds live in [github-book](https://github.com/arrmagazin/github-book) (`www_almaat/`); they read `docs/` at a release tag of this repo, and this `package.json` supplies the site's name, description and theme.
